# Security reporting

ScrollWM is an experimental developer preview. No version currently has a security-support commitment.

Do not post credentials, window contents, recovery journals, or exploitable vulnerability details in a public issue. After GitHub publication, use the repository's **Security > Report a vulnerability** route if private vulnerability reporting is enabled. If it is unavailable, request a private contact route without disclosing details.

Before publication, the maintainer must enable private vulnerability reporting or replace this policy with a working private contact. No reporting address or response-time promise has been invented here.

Useful private reports include the affected commit/version, Windows build, a minimal reproduction using non-sensitive apps, impact, and any workaround.
